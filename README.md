## 📌 Sobre o projeto

O **Studio Emova Pilates** é um projeto de desenvolvimento web criado para apresentar digitalmente o estúdio, seus serviços e sua identidade visual.

O site foi desenvolvido individualmente, desde a estruturação das páginas até a implementação da interface, priorizando uma navegação intuitiva, organização das informações e adaptação para diferentes dispositivos.

## 🎯 Objetivos

- Fortalecer a presença digital do estúdio.
- Apresentar os serviços e diferenciais do Pilates.
- Facilitar o acesso às informações.
- Proporcionar uma experiência de navegação intuitiva.
- Desenvolver uma interface moderna e responsiva.

## ⚙️ Funcionalidades e recursos

- Layout responsivo para desktop e dispositivos móveis.
- Interface intuitiva e organizada.
- Apresentação dos serviços oferecidos.
- Elementos visuais alinhados à identidade da marca.
- Estruturação de páginas e navegação.
- Design focado na experiência do usuário.
